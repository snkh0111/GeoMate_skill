# 野外实习指南：步骤、安全、白话术语库、录音技巧

本文件供首次见面、姿势检查、录音转野簿等流程加载使用。

## 首次见面话术要点

按以下顺序组织语言，亲切自然，不念稿子：

1. 欢迎与自我介绍：把自己定位成"陪你跑完整个实习的助教"。
2. 实习五步走（用大白话讲）：
   - 课前预习：看指导书，知道每天去哪、看什么。
   - 出野观察：跟老师跑路线，看露头、认岩石、测产状。
   - 现场记录：边听边记，拍照、录音、写要点。
   - 回来整理：把零碎记录整理成规范野簿。
   - 报告与考核：野簿是成绩大头，课堂上多发言也加分。
3. 辛苦提醒（关心口吻，不吓唬）：出野要爬山、晒太阳、走很多路，常常早出晚归；夏天备足水，穿防滑的鞋；提前有心理准备，到了现场就不慌。
4. 收尾：问两个分流问题（有无地质基础、是否地大学生），说明以后随时可以改。

## 地质实习基本步骤详解

### 出野前

- 通读实习指导书，弄清：实习几天、每天路线、每条路线的观察点和教学目的。
- 预习关键概念（本文件"白话术语库"可速成）。
- 检查装备（见出发清单流程）。
- 学会罗盘和放大镜的基本用法（用教学网页提前练）。

### 出野中（每个点位四件事）

1. 定点：这是几号点、在什么地方（参照物、GPS 或标志性建筑）。
2. 观察：露头是什么岩石，什么颜色，能看到哪些矿物，有没有层理、断层、节理。
3. 测量：用罗盘测产状（走向、倾向、倾角），先贴面再调平。
4. 记录：当场记下要点，拍照（整体+特写）、采标本（编号）、录音补细节。

### 出野后

- 当天整理：趁记忆新鲜，把录音和零散笔记整理进野簿。
- 不懂的点当天问：问老师、问助教、或问本助手。
- 实习结束后：基于野簿写实习报告，准备考核。

## 安全须知

- 不掉队、不单独行动，牢记集合时间和地点。
- 采石场、陡坎、采空区边缘不靠近；观察崩塌堆积体时注意上方落石。
- 敲标本时戴护目镜或戴墨镜，锤头方向不朝人。
- 海边、河边实习注意潮汐和湿滑礁石。
- 夏天防暑：带水、遮阳帽、藿香正气类药品；雷雨天停止野外作业。
- 迷路或受伤时：保持原地、打电话报告带队老师，报出明显地标。

## 白话术语库（无基础用户首次出现时配白话解释）

| 术语 | 一句话人话 |
|---|---|
| 露头 | 露出地表、能直接看到的岩石，相当于地球的"皮肤破了露出的肉" |
| 产状 | 岩层在空间里"躺"的姿势，用走向、倾向、倾角三个数描述 |
| 走向 | 岩层层面与水平面交线的方向，像书页与桌面的交线指向 |
| 倾向 | 岩层"下坡"的方向，垂直于走向 |
| 倾角 | 岩层往下倾斜的角度，0° 水平、90° 直立 |
| 节理 | 岩石里的裂缝，像饼干上的裂纹，两边没有错开 |
| 断层 | 裂开后两边错动了位置，像撕开的纸错开叠 |
| 褶皱 | 岩层被挤压弯成波浪形，像推桌布挤出的褶子 |
| 不整合 | 上下两套岩层之间隔着漫长的"空窗期"，像两本书中间撕掉了好多页 |
| 侵入岩 | 岩浆在地下慢慢冷却形成的石头，结晶粗，像慢冻的冰棍 |
| 喷出岩 | 岩浆喷出地表快速冷却，结晶细甚至带气孔，像快速冻的刨冰 |
| 变质岩 | 老岩石被高温高压"回炉改造"过的新岩石 |
| 层理 | 沉积岩一层一层的纹理，像千层蛋糕 |
| 片理 | 变质岩里矿物定向排列形成的"页理"，像一摞压实的美术纸 |
| 解理 | 矿物受力后沿固定方向裂成光滑平面的性质，像巧克力的分格槽 |
| 断口 | 矿物不沿解理破碎时的粗糙面，像掰开的馒头茬 |
| 风化 | 岩石在地表被日晒雨淋"晒酥了、泡散了"的过程 |
| 砾岩 | 鹅卵石被胶水（胶结物）粘成的石头 |
| 地质罗盘 | 测产状的仪器，像"指南针+量角器"合体 |
| 标本 | 采回来供研究的石头样品，必须编号登记 |

## 录音口述技巧（发给要录音的用户）

现场录音时按固定结构口述，转文字后可以直接填野簿：

1. 开头报点位："现在是 X 月 X 日 X 点，第 X 号点，位置在……（参照物）。"
2. 报岩性："露头主要是……（颜色、矿物、结构），初步看是……岩。"
3. 报产状："测得产状，走向……倾向……倾角……（如 300°∠35°，读作倾向 300 度、倾角 35 度）。"
4. 报现象："这里能看到……（断层/节理/褶皱/化石/接触关系），特点是……"
5. 报标本："采标本一块，编号……，取自……位置。"
6. 结尾报下一步："下一个点去……，任务是……"

提示用户：口齿放慢、一条一条说；风大时凑近麦克风；重要数字说两遍。

## 产状测量姿势自检清单（无照片时使用）

1. 选对岩面：找平整、新鲜、有代表性的层面，不是滚石面。
2. 罗盘贴面：长边贴紧岩面，不悬空、不垫手。
3. 调平：看水准气泡居中（测倾角用侧伏水准）。
4. 读数：先读走向（或倾向），再读倾角；记录格式统一为"倾向°∠倾角°"，如 300°∠35°。
5. 复测：同一岩面测 2—3 次取平均，差太大换面重测。
