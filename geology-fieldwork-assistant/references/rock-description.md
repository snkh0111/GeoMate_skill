# 岩石鉴定与标本描述规范

本文件供岩石鉴定（流程 B）、标本描述、野簿岩性描述加载使用。

## 岩石描述四要素（缺一不可）

一段合格的岩石标本描述必须写全以下四项：

### 1. 结构（矿物颗粒的"长相与排队方式"）

观察：矿物颗粒大小（粗粒 >5mm、中粒 1—5mm、细粒 <1mm）、形状（自形、半自形、它形）、颗粒之间的关系（等粒、斑状、似斑状、交代等）。
常用词：等粒结构、斑状结构、隐晶质结构、玻璃质结构、砂状结构、泥质结构、变晶结构。

### 2. 构造（岩石整体的"组装样式"）

观察：矿物或组分在空间上的排列和填充方式。
常用词：块状构造、层理构造、片理构造、片麻状构造、气孔构造、杏仁构造、流纹构造、条带状构造。

### 3. 矿物形态（主要矿物"长什么样"）

观察：每种可见矿物的晶形、粒径、颜色、解理/断口、表面特征。
例：长石呈肉红色板状短柱，粒径 2—4mm，可见两组解理；石英呈烟灰色它形粒状，油脂光泽，贝壳状断口。

### 4. 矿物特征（主要矿物的"身份信息"）

观察：每种矿物的颜色、光泽（玻璃/油脂/金属/丝绢）、硬度（能否被指甲 2.5、小刀 5.5、玻璃划动）、相对含量估计（%）。
例：黑云母，黑色片状，珍珠光泽，硬度小可被指甲划动，含量约 10%。

## 完整示例（三段，可直接当模板）

**花岗岩（手标本）**：浅肉红色，中粒等粒结构，块状构造。主要矿物为钾长石（肉红色，板状，粒径 3—5mm，玻璃光泽，两组解理，含量约 40%）、石英（烟灰色，它形粒状，油脂光泽，贝壳状断口，硬度大，含量约 30%）、斜长石（灰白色，板条状，玻璃光泽，含量约 20%），次要矿物黑云母（黑色片状，珍珠光泽，含量约 8%）。

**玄武岩（手标本）**：灰黑色，隐晶质—斑状结构，气孔构造发育，部分气孔被方解石充填呈杏仁状。斑晶为辉石（黑色短柱状，粒径 1—2mm，玻璃光泽，含量约 5%）和斜长石（灰白色细条状，含量约 5%）；基质为隐晶质，致密坚硬。

**砂岩（手标本）**：灰白色，砂状结构，层理构造清晰。碎屑颗粒以石英为主（无色透明，粒径 0.5—1mm，油脂光泽，硬度大，含量约 85%），少量长石；胶结物为硅质，致密坚硬，锤击声脆。

## 鉴定卡模板（拍照鉴定输出）

```
【岩石鉴定卡】
初步判断：××岩（可能性：高/中/低）
判断依据：
  结构：……
  构造：……
  矿物形态：……
  矿物特征：……
相似易混岩石：……（区分要点：……）
建议：拍一张新鲜断面特写可进一步确认；最终以老师现场判定为准。
```

## 鉴定规则（强制）

1. 四要素逐项写，看不到的写"照片中无法判断"，不编造。
2. 置信度只给三档：高（特征典型且齐全）、中（主要特征可见但不全）、低（只能猜到岩石大类）。口述特征推断的，最高给"中"。
3. 给出 1—2 种易混岩石和区分要点，教用户自己再核对。
4. 结尾必须带"建议找老师确认"。
5. 禁用"就是""一定是""百分之百"等定论词。

## 三大岩类速判口诀（教用户用）

- 岩浆岩：看结晶——颗粒看得见是侵入（花岗岩类），看不见或有气孔是喷出（玄武岩类）。
- 沉积岩：看层理和碎屑——一层一层、含砂含砾含化石（砂岩、砾岩、灰岩类）。
- 变质岩：看片理——矿物定向排队、能剥成薄片（片岩、片麻岩类）。
