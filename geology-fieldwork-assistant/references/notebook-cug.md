# 野簿规范：地大六栏格式、通用格式、剖面图

本文件供野簿撰写、录音转野簿、剖面图绘制流程加载使用。

## 地大野簿六栏格式（用户档案 is_cug_student=yes 时默认）

每个实习日按以下六部分依次书写，顺序固定、缺一不可：

### 1. 路线

- 内容：当天路线的名称和起止，如"路线一：马山—占甲埠村地质观察路线"。
- 来源：从用户上传的指导书文件提取；取不到时问用户，不凭记忆写。

### 2. 任务

- 内容：当天这条路线要完成什么，如"观察花岗岩侵入体与围岩接触关系，测 3 组产状，采 2 块标本"。
- 来源：同样来自指导书；指导书没有明确写时，根据当天路线内容概括并向用户确认。

### 3. 点位

- 内容：每个观察点的编号和位置，如"点 1：马山采石场东壁，距路口约 200 米"。
- 来源：用户录音转写文字。录音没报位置时标【待现场确认】。

### 4. 点义

- 内容：这个点是干什么的、观察对象是什么，如"观察花岗岩的矿物组成与结构"“观察断层破碎带及断层面产状”。
- 来源：录音转写文字；录音没有时，可根据"内容"栏概括，但需向用户说明这是概括的。

### 5. 内容

- 内容：这个点具体看到、测到、采到了什么，是野簿的主体。必须包含：
  - 岩性描述：按岩石描述四要素写（见 rock-description.md）。
  - 产状数据：统一"倾向°∠倾角°"格式，如 300°∠35°。
  - 地质现象：断层、节理、褶皱、接触关系、化石等，写清特征。
  - 标本编号：与实物标签一致。
- 来源：录音转写文字为主体；网络查到的背景资料必须标注【网络补充】，与亲眼观察分开。
- 写法：先现场后分析，先事实后解释；字迹条理清楚，一条一行。

### 6. 路线小结

- 内容：当天整条路线走完后的收获与认识：这条线揭示了哪些地质现象、各点之间有什么联系、还有什么没搞懂的问题。
- 来源：录音转写文字 + 当天各点内容的归纳。
- 提醒：小结是老师重点看的部分，写出"我理解了什么"，不是把各点内容复制一遍。

## 通用野簿格式（非地大用户）

按日期分节，每节包含：日期天气、路线与任务、各观察点记录（位置、岩性描述、产状、现象、标本）、当日小结。字段要求同六栏对应部分。

## 数据来源标注规则（野簿内容强制）

| 内容 | 来源 | 缺失时 |
|---|---|---|
| 路线、任务 | 指导书文件 | 问用户 |
| 点位、点义、内容、路线小结 | 录音转写文字 | 标【待现场确认】 |
| 背景资料、区域地质 | 网络搜索 | 标注【网络补充】 |

铁律：不编造用户没观察到的现象和数据。拿不准的标出来，宁可空着。

## 地质剖面图要求

合格剖面图五要素（交付前逐项检查）：

1. 图名：如"马山采石场信手地质剖面图"。
2. 方向：标明剖面线方向（如 NE45°）。
3. 比例尺：数字比例尺或线段比例尺。
4. 图例：每种地层/岩性一种花纹或颜色，旁边配图例框。
5. 产状标注：在对应地层位置标"倾向°∠倾角°"。

### 剖面图数据格式（draw_profile.py 的输入）

引导用户按下面的 JSON 结构提供数据，缺项逐项问齐：

```json
{
  "title": "马山采石场信手地质剖面图",
  "direction": "NE45°",
  "scale": "1:1000",
  "topography": [[0, 120], [50, 135], [100, 128], [150, 142]],
  "strata": [
    {"name": "花岗岩", "color": "#e8a0a0", "pattern": "cross", "dip": "300°∠35°", "thickness": 40},
    {"name": "砂岩", "color": "#f2d38a", "pattern": "dots", "dip": "295°∠30°", "thickness": 25}
  ],
  "notes": "点1附近见断层破碎带"
}
```

字段说明：

- `topography`：地表高程点列表，每项为 [水平距离米, 高程米]，从左到右。
- `strata`：从左到右（或从老到新）的地层列表；`thickness` 为视厚度（米）；`pattern` 可选 cross（侵入岩网纹）、dots（砂岩点状）、lines（页岩线状）、brick（灰岩砖墙状）、blank。
- `notes`：需要标注在图上的补充说明，可省略。

脚本输出 SVG 文件，可直接用浏览器打开，也可插入报告。脚本不可用时，把数据整理成文字绘制说明（起点、方位、各层界线位置与倾角）交给用户手绘。

## 野簿常见扣分点（交付前提醒用户）

- 六栏缺栏或顺序乱。
- 岩性描述缺要素（结构、构造、矿物形态、矿物特征少一项）。
- 产状只记了一个数，或格式混乱。
- 小结抄点位内容，没有自己的认识。
- 网络抄来的大段背景没有标注，冒充现场观察。
- 标本编号和实物对不上。
