# 可选增强配置指南

本 Skill 核心功能零配置可用。以下增强项（依赖标识见各节）配置一次即可，不配置时按 skill-dependencies.json 中的降级规则执行。所有配置只读取状态，不在对话中粘贴任何凭据。

## 资料库（依赖标识：workbuddy-library）

- 用途：把成果保存为在线文档，跨设备随时查看。
- 类型：WorkBuddy 内置能力，无需安装。
- 官方主页：https://workbuddy.cn/
- 官方文档：https://workbuddy.cn/
- 配置步骤：
  1. 确认 WorkBuddy 为正式版本并已登录账号。
  2. 对话中直接说"把这份野簿保存到资料库"。
  3. 首次使用按界面提示确认即可。
- 凭据存储：使用当前登录的 WorkBuddy 账号，不另需凭据。
- 验证：让助手在资料库创建一个测试文档，能看到即通过。
- 撤销：资料库文档可在资料库界面删除；不需要时在对话中说明不再使用。
- 核验日期：2026-08-15

## 腾讯文档（依赖标识：tencent-docs）

- 用途：把成果同步为腾讯文档，方便在线分享协作。
- 类型：WorkBuddy 连接器，浏览器登录授权。
- 官方主页：https://docs.qq.com/
- 官方文档：https://docs.qq.com/
- 登录网址：https://docs.qq.com/
- 授权路径：WorkBuddy 设置 → 连接器 → 腾讯文档 → 连接并按提示完成授权。
- 配置步骤：
  1. 打开 WorkBuddy 设置，进入连接器列表。
  2. 找到"腾讯文档"，点击连接。
  3. 在弹出的腾讯文档官方页面登录并同意授权。
  4. 返回 WorkBuddy，确认连接器显示"已连接"。
- 凭据存储：由 WorkBuddy 连接器托管，不要在对话中粘贴账号、密码或 Cookie。
- 验证：连接成功后，让助手"读一下我最近的一篇腾讯文档标题"，能读出即通过。
- 过期与轮换：授权失效时重新走一遍连接流程即可。
- 撤销：在 WorkBuddy 连接器面板断开连接；或在腾讯文档账号的授权管理中撤销第三方授权。
- 核验日期：2026-08-15

## Python 3.10+（依赖标识：python-runtime）

- 用途：运行指导书 PDF 提取和剖面图绘制脚本。不装也不影响对话功能，改用粘贴文字和文字绘制说明。
- 官方主页：https://www.python.org/
- 官方文档：https://www.python.org/doc/
- 官方下载：https://www.python.org/downloads/
- 配置步骤：
  1. 从官方下载页获取 3.10 或更高版本安装包。
  2. 安装时勾选 Add python.exe to PATH。
  3. 重开终端执行 python --version 验证。
- 凭据存储：不需要。
- 验证：python --version 输出 3.10 及以上即通过。
- 撤销：通过系统"应用与功能"卸载 Python。
- 核验日期：2026-08-15

## 文件写入权限（依赖标识：file-write）

- 用途：把成果保存为本地文件（Markdown / HTML / SVG）。
- 官方主页：https://support.microsoft.com/windows
- 官方文档：https://support.microsoft.com/windows
- 配置步骤：
  1. 选一个当前用户有写权限的目录作为成果目录（如桌面或文档下新建文件夹）。
  2. 写入被拒绝时，检查文件夹属性的只读设置，或更换目录。
- 凭据存储：不需要。
- 验证：在目标目录新建一个测试文件并能打开，即具备写权限。
- 撤销：不需要；删除成果目录下的文件需用户明确同意。
- 核验日期：2026-08-15

## 网络连接（依赖标识：web-search）

- 用途：网络搜索补充材料外内容（产出中标注【网络补充】）。
- 官方主页：https://www.baidu.com/
- 官方文档：https://www.baidu.com/
- 配置步骤：
  1. 确认电脑已连接互联网。
  2. 使用校园网或代理时，确认代理设置在系统或浏览器中生效。
- 凭据存储：不需要。
- 验证：浏览器能打开任意网页即网络可用。
- 撤销：不需要。
- 核验日期：2026-08-15
