# 常见问题与反模式

用户遇到使用问题、说"卡住了""不会用""怎么办"时加载本文件。回答时用大白话，先给能立刻做的下一步。

## 常见问题

**Q：怎么唤醒这个助手？必须说固定的话吗？**
不用。跟实习沾边的说法都行："这块石头是啥""产状怎么测""老师讲的没记下来""下周出野要准备啥"都能识别。说不准的时候直接描述你遇到的事，助手会自己判断或反问你一句。

**Q：指导书 PDF 读不出来怎么办？**
两种情况：① 脚本提取失败——把 PDF 里的文字复制粘贴过来即可，效果一样；② 扫描件（图片型 PDF）——先做成文字版：手机拍照识字（微信"提取文字"、QQ 扫一扫都行），或只摘关键章节手打。

**Q：录音怎么转成文字？**
三个随手办法：微信聊天里发语音后长按选"转文字"；手机自带录音机一般有"转写"按钮；讯飞听见等 App 适合长录音。转完把文字发给助手。现场录音时按"报点位→报岩性→报产状→报现象→报标本"的口诀口述，转写整理效果最好。

**Q：电脑没装 Python，影响使用吗？**
只影响两件小事：PDF 自动提取（改为粘贴文字）和剖面图自动绘制（改为给你文字版绘制说明，手绘或用绘图软件）。其余所有功能照常。

**Q：不拍照能鉴定岩石吗？**
能。口述你看到特征——颜色、光泽、硬度（指甲/小刀划不划得动）、颗粒粗细、有没有分层——助手据此推断，但置信度最高只给"中"，并会建议你补拍照片或找老师确认。

**Q：鉴定结果能直接写进作业吗？**
能参考，别照抄当结论。鉴定卡是"辅助初判"，把握度写在上面；正式作业以老师现场判定为准。

**Q：成果保存在哪？能存到网上吗？**
默认存成你电脑上的文件（Markdown/网页/图），永久能打开。想在线看：说一声"存到资料库"或"存到腾讯文档"（需先连接一次，见配置指南）。

**Q：想改"有没有地质基础""是不是地大学生"的设置？**
直接说："我其实有基础""我不是地大的"，助手会更新并告诉你新设置已生效。

**Q：画剖面图要我提供什么？**
四样东西：剖面方向（如 NE45°）、地表起伏（几个点的距离和高程）、各地层的厚度和产状、地层名称。说不全也没关系，助手会一项一项问你。

**Q：我不是地大学生，野簿格式能用吗？**
能。不是地大学生就用通用格式（日期天气、路线任务、各点记录、当日小结），字段要求一样严谨。

**Q：它帮我从网上查的内容会标出来吗？**
会。所有网络补充内容都标【网络补充】，和你亲眼观察、自己材料里的内容严格分开，不会混写。

**Q：能帮我编观察数据、替我写作业吗？**
不能。没观察到的现象和数据一律不编，标【待现场确认】；报告只搭框架，内容你自己填。这是保护你——实习成绩以真实记录为准。

## 反模式（常见错误用法 → 正确姿势）

| 错误用法 | 为什么不行 | 正确姿势 |
|---|---|---|
| 直接发录音/音频文件 | 助手不处理音频 | 手机先转文字，发文字 |
| 发张照片就要"确定答案" | 照片鉴定是辅助初判，有误差 | 看置信度，拍新鲜断面特写复核，找老师确认 |
| 让它编没看到的断层、化石 | 学术诚信底线，编了害你 | 没看到的标【待现场确认】，回现场补 |
| 把网上抄的背景写进野簿当现场观察 | 老师一眼能看穿，且违反规则 | 网络内容单独标注【网络补充】 |
| 一次发多份不同课程/实习的 PDF 不说明 | 内容会串 | 一次一份，说明是哪次实习 |
| 看不懂报错就关掉 | 报错都能翻译成人话 | 直接问"这什么意思、我现在怎么办" |
| 让助手保证"老师肯定问这些" | 课堂问题只是发言素材 | 用来准备思路，不赌原题 |
